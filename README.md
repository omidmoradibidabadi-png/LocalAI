# LocalAI / LocalChatBot

Official development repository for the LocalChatBot project.

## Current version
**V2.2.3 — RAG/Qdrant/Spatial Routing Fix**

Versioning from V2.2.3 onward is tracked in this repository. Each release directory contains the regression context, validation status, and package checksum.

The application is offline-first and uses local Gemma, EmbeddingGemma, Qdrant, Elasticsearch, SQLite, OCR and GIS components.
